Celebrating Computing & IT Innovation at STI College Laoag

The CITS Project Showcase is an interactive college exhibition portal designed to highlight student-engineered software systems, web platforms, and hardware prototypes across computer science and information technology disciplines.

Web & Mobile Portals

Featuring responsive web applications, cloud dashboards, and sideloadable Android packages developed for community and organizational use.
