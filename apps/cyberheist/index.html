Think like a defender, investigate the clues, and put your security instincts to the test. Cyberheist turns cybersecurity fundamentals into a fast, command-driven arcade challenge.

Each run draws five objectives from an isolated training simulation. No real systems are accessed; the focus is on careful analysis, ethical decision-making, and learning how to spot security risks.

MISSION TYPES // 01—05

Five ways to outsmart the system.

Every challenge rewards observation and reasoning—not real-world access or intrusion.

01 // CREDENTIALS

Password Crack

Read the clues and identify the weak credential in a simulated scenario.

02 // CIPHER

Code Breaker

Decode a message by following the evidence and applying pattern recognition.

03 // SIGNAL

Log Analysis

Separate a suspicious event from routine activity in a log-based puzzle.

04 // RESPONSE

Security Breach

Choose a safe, responsible response to a fictional security incident.

05 // EVIDENCE

Digital Forensics

Follow a trail of fictional evidence and find the signal that explains what happened.

PLAYER GUIDE // TERMINAL BASICS

Type commands. Follow the evidence.

01 / START

Launch your run

Choose a difficulty, set a callsign, and begin a training run.

02 / SCAN

Map the training node

Type scan to review the objective.

03 / INSPECT

Read the evidence

Use inspect to see clues and possible findings.

04 / ANALYZE

Submit your finding

Use analyze B to submit a candidate answer.

05 / CONTINUE

Move to the next objective

After resolving a challenge, type next. Use help to review available commands.
