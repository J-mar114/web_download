Mission Modules 01 — 05

Five Cybersecurity Challenges

Every challenge rewards systematic observation, pattern recognition, and sound defensive security principles.

01 // LOG ANALYSIS +100 PTS

Login Outlier

Examine harmless event streams, compare source IP addresses and timestamps, and identify the single anomalous sign-in attempt.

02 // THREAT MITIGATION +100 PTS

Unknown USB

Triage a physical security risk: determine how to handle an untrusted flash drive found on-site without triggering automated autorun malware.

03 // CIPHER BREAKING +100 PTS

Shift Cipher

Decode obfuscated messages using frequency analysis and Caesar shift patterns to uncover the hidden operator passphrase.

04 // HASH VERIFICATION +100 PTS

File Integrity

Cross-reference SHA-256 cryptographic checksums against baseline hashes to locate tampered binaries and unauthorized file replacements.

05 // INCIDENT RESPONSE +100 PTS

The Leaked Note & Incident Containment

Connect multiple fragmented clues across access control lists, network artifacts, and memory strings to reconstruct the incident and select the correct containment action.

Terminal Cheatsheet

Interactive Command Syntax

The Cyberheist terminal accepts lightweight commands directly through the input bar or mobile prompt.

01 / DISCOVERY scan

Map Training Node

Initializes the training node, verifies isolated routing, and prepares the challenge evidence packet.

02 / FORENSICS inspect

Read Evidence Packet

Dumps event logs, server timestamps, user records, and candidate answers (A, B, C, D) to screen.

03 / SUBMISSION analyze <opt>

Submit Candidate Answer

Submit your verified conclusion (e.g. analyze A) to score reputation points.

04 / ASSISTANCE hint

Unlock Guidance

Stuck on a tricky cipher? Unlock a hint for -25 simulation points to point you in the right direction.

05 / ADVANCE next

Seal Node & Advance to Next Stage

Locks in your verified stage score and advances to the next challenge. Type help at any time for the full command list.

Ethical Sandbox Guarantee

Cyberheist is strictly designed as an educational training application. Every command, log line, and evidence packet is simulated locally:

  • No live network access: Zero packets sent to outside domains or hosts.
  • Fictional targets: All IP addresses (RFC 5737 test nets) and usernames are synthetic.
  • Defensive focus: Promotes safe credential hygiene, log audits, and rapid containment.
